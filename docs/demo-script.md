# Demo Script

## Demo Goal

Show how Norvix AS can connect existing systems and reduce manual work between email/forms, Microsoft 365 style document handling, company lookup, accounting/project basis, AI-assisted review, secure delivery, audit log, and reporting.

Target length: 5 minutes.

## Setup

Demo tenant:

- Agder Drift & Service AS

Demo user:

- Operations user or admin in the demo tenant.

Demo case:

- Incoming service request with attachments and incomplete customer/document metadata.

## Storyline

"Agder Drift & Service AS already uses Microsoft 365, SharePoint, Outlook, Excel, accounting/project systems, and Power BI. The issue is that people still copy information between systems. Norvix WorkFlow Hub turns that manual flow into a controlled case workflow."

## Step 1 - Dashboard

Show:

- new intakes;
- waiting review;
- missing information;
- documents needing review;
- integration failures;
- cases ready for delivery.

Message:

"This is not another isolated system. It is an operational control layer for work already happening across existing tools."

## Step 2 - Intake Inbox

Open a new intake from mock email/form.

Show:

- source;
- subject/body;
- attachments;
- status `New`.

Message:

"Requests can arrive from email, forms, manual entry, or API. The first value is that they become structured and trackable."

## Step 3 - AI Suggestions

Run mock AI analysis.

Show suggestions:

- customer;
- organization number;
- category;
- urgency;
- tasks;
- document metadata;
- missing information;
- summary.

Message:

"AI helps prepare the work, but it does not decide. Suggestions stay pending until a person approves or edits them."

## Step 4 - Human Review

Approve or edit suggestions.

Show:

- review queue;
- changed fields;
- audit event.

Message:

"This is AI-assisted administration with human control and auditability."

## Step 5 - Convert to Case

Convert intake to case.

Show Case Workspace tabs:

- Overview;
- Tasks;
- Documents;
- Customer;
- Integrations;
- Activity.

Message:

"The approved intake becomes a case workspace, not another spreadsheet row."

## Step 6 - Brreg Lookup

Search Bronnoysundregistrene by organization number or name.

Show:

- selected company data;
- source timestamp;
- customer enrichment.

Message:

"Norwegian company data can be looked up and stored with source traceability."

## Step 7 - Document Workflow

Upload or open attached document.

Show:

- document version;
- AI classification;
- human approval;
- expiry metadata;
- linked case.

Message:

"Documents are no longer just files in a folder. They become reviewed, linked, versioned case evidence."

## Step 8 - Missing Information

Show checklist.

Message:

"The system shows what is blocking delivery instead of requiring someone to remember it manually."

## Step 9 - Integration Dashboard

Show connector states:

- Brreg;
- Microsoft Graph/SharePoint mock;
- accounting/project mock;
- Power BI/Fabric export mock.

Message:

"Integrations can start as mocks and then be activated one by one. The architecture is prepared for real APIs."

## Step 10 - Delivery Package

Generate PDF summary and create delivery link.

Show:

- selected documents;
- expiring secure link;
- external recipient page;
- access log;
- revoke action.

Message:

"The customer gets a controlled delivery link, not a loose email thread with attachments."

## Step 11 - Audit and Analytics

Show:

- audit events;
- case status metrics;
- export option.

Message:

"Management gets operational visibility, and the organization gets a traceable record of what happened."

## Closing Message

"This demo shows the kind of practical automation Norvix can build: connecting the systems clients already have, reducing double registration, adding AI where it helps, and keeping people in control."
