# Product Brief

## Product Name

Norvix WorkFlow Hub

## Subtitle

Fra e-post og skjema til sak, dokumentasjon, fakturagrunnlag og rapportering - uten dobbeltregistrering.

## Purpose

Norvix WorkFlow Hub demonstrates how Norvix AS can help Norwegian organizations connect existing systems and reduce manual administrative work across email, forms, Microsoft 365, documents, accounting/project systems, AI-assisted review, secure delivery, and reporting.

## Target Message

Norvix AS helps Norwegian organizations with integrations, data flow, document workflow, and AI-ready internal tools when they already have digital systems but still work manually between them.

## Demo Customer

Use fictional data only.

- Company: Agder Drift & Service AS
- Country: Norway
- Industry: technical services, operations, B2B service
- Employees: 45
- Current tools: Microsoft 365, SharePoint, Outlook, Excel, Tripletex/PowerOffice/Fiken-style accounting, Power BI

## Core Problem

Requests arrive through email, forms, and ad hoc channels. Documents are stored in email attachments, SharePoint folders, and local workspaces. Customer and project data exists in accounting/project tools. Status tracking and management reporting often fall back to Excel.

The pain is:

> We have digital tools, but people still move data manually between them.

## Value Proposition

Norvix WorkFlow Hub shows that Norvix can:

- capture requests into a structured intake workflow;
- enrich customer/company data from Norwegian public registers;
- classify documents and extract metadata;
- keep human review in control of AI suggestions;
- create a case/project workspace;
- prepare accounting/project basis without issuing invoices;
- generate secure customer delivery packages;
- produce operational visibility through dashboards and exports;
- maintain auditability and privacy-aware controls.

## MVP Success Criteria

The MVP is successful when a 5-minute end-to-end demo can show:

1. Intake created from manual/mock source.
2. AI suggestions generated and clearly labeled.
3. Human review approval/edit flow.
4. Conversion to case workspace.
5. Brreg company lookup and customer enrichment.
6. Document upload, classification, versioning, and approval.
7. Missing information checklist.
8. Delivery package with PDF summary and secure expiring link.
9. Audit log and dashboard metrics.

## Audience

Primary audiences:

- Norwegian SMEs with Microsoft 365 and manual admin workflows.
- Microsoft-oriented consultants and partners.
- Public sector or public-sector-adjacent organizations needing controlled workflow and auditability.
- Potential Norvix clients evaluating integration and automation capability.

## Positioning

This is not a narrow vertical SaaS. It is a realistic integration and workflow showcase for organizations that already have tools but need better flow between them.
