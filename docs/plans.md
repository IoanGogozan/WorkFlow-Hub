historical plans do not override those documents.

## Supporting documents

Requirements, architecture, testing, deployment, walkthrough, and security
documents constrain or describe the product, but they are not competing
implementation plans. Update them when a numbered active-plan task explicitly
changes their subject.

## Maintenance rule

New implementation directions must update this registry. Keep exactly one
plan under **Active** and remove a replaced implementation plan after any
still-relevant technical facts have been incorporated into current docs.
